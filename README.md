# Trainer Session Attendance Dashboard

A simple React app to mark and track trainer attendance across sessions.

## Features
- Add/remove sessions
- Add/remove trainers
- Mark attendance as Present / Absent per session
- Live stats: Present, Absent, Unmarked, Overall attendance %

## Getting Started

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

## Tech Stack
- React
- Vite
- Tailwind CSS
- lucide-react (icons)
